# 商品图片来源说明

本目录下的商品图片**不是**从小米商城、京东等电商网站抓取的商品摄影图,
而是通过 [loremflickr.com](https://loremflickr.com/) 从 Flickr 检索的**免费图库照片**。

- 用途: 购物商城系统演示 / 课程设计种子数据
- 检索方式: 按关键词(如 `mobile-phone`、`medicine`)随机取图, 使用 `lock` 参数固定结果
- 授权: 图片版权归 Flickr 原作者所有, 按 loremflickr 服务条款供免费使用;
  若用于正式发布, 建议核对具体图片的授权条款, 或替换为自己的商品实拍图
- 复现: `node scripts/fetch-product-images.mjs` (已存在的文件会跳过)
